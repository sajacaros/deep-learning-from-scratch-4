# CHAPTER 7 신경망과 Q 러닝
- 6장까지 `Q`를 **딕셔너리(표)** 로 들고 있었음. 12칸짜리 그리드 월드니까 가능했던 일
- 표가 감당하지 못하는 경우
  |상황 |예 |표의 문제 |
  |:--|:--|:--|
  |상태가 아주 많음 |바둑(`10^170`), 아타리 화면 |메모리에 담을 수 없음 |
  |상태가 **연속값** |카트 폴의 각도·속도 |칸을 나눌 수 없음 |
  |비슷한 상태끼리 |각도 `0.30`과 `0.31` |별개의 칸이라 배운 것이 공유되지 않음 |
- 이 장에서는 표를 **신경망**으로 대신함 — `Q(s,a)`를 매개변수 몇 개짜리 함수로 근사
  - 마지막 줄이 특히 중요함 — 신경망은 **비슷한 입력에 비슷한 출력**을 내므로 경험이 일반화됨
- 도구는 **DeZero**를 씀(『밑바닥부터 시작하는 딥러닝 ❸』에서 만든 프레임워크)
  - 파이토치 버전은 [`../pytorch/`](../pytorch/)에 따로 있음
## 7.1 DeZero 기초
### 7.1.1 DeZero 사용법
- ![](../images/figures/fig%207-1.png)
  - DeZero는 3권에서 밑바닥부터 만든 딥러닝 프레임워크
  - 파이토치·텐서플로와 같은 **Define-by-Run**(동적 계산 그래프) 방식이라 사용법이 비슷함
- 설치: `uv sync --group dezero` (자세한 사정은 [`../pyproject.toml`](../pyproject.toml) 주석 참고)
- 핵심 3요소
  |요소 |역할 |
  |:--|:--|
  |`Variable` |값과 미분(`grad`)을 담는 상자 |
  |`dezero.functions`(`F`) |`matmul`, `sigmoid`, `relu`, `mean_squared_error` 등 |
  |`backward()` |역전파로 모든 `Variable`의 `grad`를 채움 |
### 7.1.2 다차원 배열(텐서)과 함수
- ![](../images/figures/fig%207-2.png)
  - 스칼라 → 벡터 → 행렬. 축의 개수를 **차원**이라고 부름
- ![](../images/equations/e%207-1.png)
  - 벡터의 내적([식 7.1]) — `a·b = a_1b_1 + ... + a_nb_n`
- ![](../images/figures/fig%207-3.png)
  - 행렬 곱 — **왼쪽 행렬의 한 행**과 **오른쪽 행렬의 한 열**을 내적한 것이 결과의 한 원소
  - **볼 곳**: 하늘색으로 칠해진 `(1, 2)` 행과 `(5, 7)` 열이 `1×5 + 2×7 = 19`가 됨
- ![](../images/figures/fig%207-4.png)
  - 형상 규칙 — `(3×2)(2×4) = (3×4)`
  - **볼 곳**: 가운데 **`2`끼리 맞아야** 곱셈이 성립하고, 바깥의 `3`과 `4`가 결과 형상이 됨
  - 신경망 코드에서 나는 오류의 대부분이 이 규칙 위반
- 예제 코드: [`s01_dezero1.py`](s01_dezero1.py)
```python
a = np.array([1, 2, 3]); b = np.array([4, 5, 6])
a, b = Variable(a), Variable(b)   # 생략 가능 — ndarray를 넣으면 자동 변환됨
c = F.matmul(a, b)
print(c)
```
```
variable(32)
variable([[19 22]
          [43 50]])
```
  - `1×4 + 2×5 + 3×6 = 32`, 그리고 그림 7-3의 행렬 곱
  - `Variable`로 감싸는 것을 생략해도 되는 이유 — DeZero가 `ndarray`를 자동으로 변환함
### 7.1.3 최적화
- 신경망 학습이란 결국 **손실 함수를 가장 작게 만드는 매개변수 찾기**
- 연습용으로 **로젠브록 함수**를 최소화해봄 — 최솟값이 `(1, 1)`인 골짜기 모양 함수
  - `y = 100(x_1 - x_0²)² + (x_0 - 1)²`
  - 골짜기가 좁고 길게 휘어 있어 최적화 알고리즘의 시험대로 자주 쓰임
- 예제 코드: [`s02_dezero2.py`](s02_dezero2.py)
```python
x0 = Variable(np.array(0.0))
x1 = Variable(np.array(2.0))

for i in range(10000):
    y = rosenbrock(x0, x1)

    x0.cleargrad()      # 이전 반복에서 더해진 미분을 초기화
    x1.cleargrad()
    y.backward()        # 미분(역전파)

    x0.data -= lr * x0.grad.data    # 경사 하강법
    x1.data -= lr * x1.grad.data
```
```
variable(0.9944984367782456) variable(0.9890050527419593)
```
- **볼 곳**: `(0.994, 0.989)` — 10,000번 반복해도 정답 `(1, 1)`에 완전히 닿지는 않음
  - 골짜기 바닥이 평평해 경사가 거의 `0`이라 마지막 구간에서 진행이 느려짐
- **`cleargrad()`를 잊으면 안 되는 이유** — DeZero(와 파이토치)의 `grad`는 **누적됨**
  - 지우지 않으면 이전 반복의 기울기가 더해져 갱신이 폭주함
  - 뒤의 예제에서는 `model.cleargrads()`로 모델 전체의 기울기를 한 번에 지움
- **경사 하강법**(gradient descent) — `매개변수 ← 매개변수 - lr × 기울기`
  - `lr`(학습률)은 한 걸음의 크기. 너무 크면 발산하고 너무 작으면 느림
## 7.2 선형 회귀
### 7.2.1 토이 데이터셋
- ![](../images/figures/fig%207-5.png)
  - `y = 5 + 2x + 노이즈`로 만든 데이터 100개
  - **볼 곳**: 점들이 **직선 주변에 흩어져 있음**. 노이즈 때문에 정확히 한 줄이 아님
```python
np.random.seed(0)
x = np.random.rand(100, 1)
y = 5 + 2 * x + np.random.rand(100, 1)
```
  - 우리가 찾아야 할 참값은 `W = 2`, `b = 5.5`(노이즈의 평균 `0.5`가 절편에 더해짐)
### 7.2.2 선형 회귀 이론
- ![](../images/figures/fig%207-6.png)
  - **선형 회귀** — 데이터를 가장 잘 설명하는 직선 하나를 찾는 것
  - **볼 곳**: 각 점에서 직선까지의 세로 선분(**잔차**)
  - 이 잔차들을 가장 작게 만드는 직선이 답
- ![](../images/equations/e%207-2.png)
  - **평균 제곱 오차**(mean squared error)([식 7.2])
  - `L = (1/N) Σ (Wx_i + b - y_i)²`
  - 잔차를 제곱하는 이유 — 부호를 없애고, 큰 오차에 더 큰 벌점을 주기 위해
- ![](../images/figures/fig%207-7.png)
  - `x`(100×1)와 `W`(1×1)를 곱해 `y`(100×1)를 얻음
  - **볼 곳**: 데이터 100개를 **for문 없이 행렬 곱 한 번**으로 계산한다는 것
- ![](../images/figures/fig%207-8.png)
  - 입력이 4차원인 경우로 확장 — `(100, 4) × (4, 1) = (100, 1)`
  - **볼 곳**: 파란 강조 표시가 보여주는 계산. **한 데이터(한 행)** 와 `W`(열)의 내적이 한 예측값
  - 이 구조 덕분에 입력 차원이 늘어도 코드가 그대로임
### 7.2.3 선형 회귀 구현
- 예제 코드: [`s03_dezero3.py`](s03_dezero3.py)
```python
W = Variable(np.zeros((1, 1)))
b = Variable(np.zeros(1))

def predict(x):
    return F.matmul(x, W) + b       # 100개를 일괄 계산

def mean_squared_error(x0, x1):
    diff = x0 - x1
    return F.sum(diff ** 2) / len(diff)

for i in range(100):
    y_pred = predict(x)
    loss = mean_squared_error(y, y_pred)

    W.cleargrad(); b.cleargrad()
    loss.backward()
    W.data -= lr * W.grad.data
    b.data -= lr * b.grad.data
```
- **볼 곳**: 손실을 직접 정의해도 되고 `F.mean_squared_error()`를 써도 됨
  - 다만 DeZero의 내장 함수는 **중간 계산 결과를 덜 저장**하도록 최적화돼 있어 메모리에 유리
```
42.296340129442335      ← 0회
0.24915731977561134     ← 10회
...
0.07987086218625004     ← 90회
====
W = [[2.11807369]]
b = [5.46608905]
```
- **볼 곳**: 손실이 `42.3 → 0.25`로 **첫 10회 만에 급락**한 뒤 완만해짐
  - 처음에는 `W=0, b=0`이라 예측이 전부 `0` → 오차가 클 수밖에 없음
  - 학습된 `W = 2.12`, `b = 5.47` — 데이터를 만든 참값(`2`, `5.5`)에 가까움
  - 정확히 맞지 않는 것은 노이즈가 섞인 표본 100개로 추정했기 때문
- ![](../images/figures/fig%207-9.png)
  - 학습된 직선(빨강)이 점들의 한가운데를 지남
## 7.3 신경망
### 7.3.1 비선형 데이터셋
- ![](../images/figures/fig%207-10.png)
  - `y = sin(2πx) + 노이즈`로 만든 데이터
  - **볼 곳**: 올라갔다 내려갔다 다시 올라오는 **곡선 모양**
  - 직선으로는 아무리 잘 맞춰도 이 형태를 따라갈 수 없음 → 선형 회귀의 한계
### 7.3.2 선형 변환과 활성화 함수
- **선형 변환**(linear transformation) `y = xW + b`을 여러 번 겹치면 될까? — **안 됨**
  - `(xW_1 + b_1)W_2 + b_2 = x(W_1W_2) + (b_1W_2 + b_2)` — 결국 하나의 선형 변환
  - 층을 아무리 쌓아도 표현력이 늘지 않음
- 그래서 층 사이에 **비선형 함수**를 끼워 넣음 — **활성화 함수**(activation function)
- ![](../images/figures/fig%207-11.png)
  - **왼쪽(시그모이드)**: `y = 1/(1+e^{-x})` — 값을 `0~1` 사이로 압축하는 S자 곡선
  - **오른쪽(ReLU)**: `y = max(0, x)` — 음수는 `0`, 양수는 그대로
  - **볼 곳**: 시그모이드는 양 끝이 **평평해짐**. 그 구간에서는 기울기가 거의 `0`이라
    역전파 신호가 사라짐(**기울기 소실**) → 층이 깊어지면 ReLU가 유리
  - 이 장에서는 얕은 회귀에 시그모이드, Q 신경망에 ReLU를 씀
### 7.3.3 신경망 구현
- 2층 신경망을 손으로 쓰면
```python
def predict(x):
    y = F.linear(x, W1, b1)
    y = F.sigmoid(y)          # 활성화 함수
    y = F.linear(y, W2, b2)
    return y
```
  - `W1`은 `(1, 10)`, `W2`는 `(10, 1)` — 중간층의 크기가 `10`
  - 중간층을 키울수록 표현력이 커지지만 매개변수도 늘어남
- 문제: 층이 늘어날 때마다 `W`, `b`를 손으로 선언하고 `cleargrad()`도 하나씩 불러야 함
### 7.3.4 계층과 모델
- **계층**(`dezero.layers.Linear`) — `W`와 `b`를 자기 안에 들고 있는 객체
  - **입력 크기를 적지 않아도 됨** — 첫 호출 때 들어온 데이터를 보고 `W`를 자동 생성
- **모델**(`dezero.Model`) — 계층들을 묶고, 매개변수를 한 번에 다루게 해주는 그릇
```python
class TwoLayerNet(Model):
    def __init__(self, hidden_size, out_size):
        super().__init__()
        self.l1 = L.Linear(hidden_size)   # 출력 크기만 지정
        self.l2 = L.Linear(out_size)

    def forward(self, x):
        y = F.sigmoid(self.l1(x))
        y = self.l2(y)
        return y
```
- `model(x)`처럼 부르면 `forward()`가 실행되고, `model.cleargrads()`로 모든 기울기를 한 번에 지움
### 7.3.5 옵티마이저(최적화 기법)
- 매개변수 갱신 규칙을 분리한 것이 **옵티마이저**
```python
model = TwoLayerNet(10, 1)
optimizer = optimizers.SGD(lr)   # 옵티마이저 생성
optimizer.setup(model)           # 최적화할 모델을 등록

for i in range(iters):
    y_pred = model(x)
    loss = F.mean_squared_error(y, y_pred)

    model.cleargrads()
    loss.backward()
    optimizer.update()           # W.data -= lr * grad 를 대신함
```
- `SGD` 말고도 `MomentumSGD`, `Adam` 등이 있고 **한 줄만 바꾸면 교체됨**
  - 8장 DQN에서는 `Adam`을 씀

## 7.4 Q 러닝과 신경망
### 7.4.1 신경망의 전처리
- 그리드 월드의 상태는 `(2, 0)` 같은 좌표. 이대로 신경망에 넣으면 안 됨
  - `(0,3)`과 `(1,0)`처럼 숫자가 가까워도 의미가 전혀 다를 수 있음
  - 좌표값의 크기 자체가 의미 없는 순서 정보를 주입함
- 그래서 **원핫 벡터**(one-hot vector)로 바꿈 — 12칸이므로 길이 12
```python
def one_hot(state):
    HEIGHT, WIDTH = 3, 4
    vec = np.zeros(HEIGHT * WIDTH, dtype=np.float32)
    y, x = state
    idx = WIDTH * y + x
    vec[idx] = 1.0
    return vec[np.newaxis, :]      # (1, 12) — 배치 차원을 붙임
```
- **볼 곳**: 마지막 줄의 `[np.newaxis, :]`
  - 신경망은 항상 **`(배치 크기, 특징 수)`** 형태를 기대함
  - 데이터가 하나뿐이어도 `(12,)`가 아니라 `(1, 12)`로 넣어야 함
- 원핫 인코딩의 한계도 알아둘 것 — **칸 사이의 거리 정보가 사라짐**
  - `(0,0)`과 `(0,1)`이 이웃이라는 것을 벡터만 보고는 알 수 없음
  - 그래서 이 예제에서는 신경망의 '일반화' 이점이 거의 나타나지 않음(7.4.3에서 확인)
### 7.4.2 Q 함수를 표현하는 신경망
- ![](../images/figures/fig%207-13.png)
  - **위**: `(s, a)`를 함께 넣고 **스칼라 하나**를 출력하는 구조
  - **아래**: `s`만 넣고 **행동 개수만큼** 출력하는 구조
  - **볼 곳**: 아래 구조는 한 번의 순전파로 **네 행동의 Q 값을 동시에** 얻음
  - Q 러닝에는 `max_a Q(s,a)`가 필요한데, 위 구조라면 행동 수만큼 순전파해야 함
  - 그래서 아래 구조를 씀(DQN도 마찬가지)
```python
class QNet(Model):
    def __init__(self):
        super().__init__()
        self.l1 = L.Linear(100)  # 중간층의 크기
        self.l2 = L.Linear(4)    # 행동의 개수

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = self.l2(x)
        return x
```
- 출력층에 활성화 함수를 두지 않는 이유 — `Q` 값은 음수도 될 수 있는 **임의의 실수**
### 7.4.3 신경망과 Q 러닝
- ![](../images/equations/e%207-3.png)
  - 6장 Q 러닝의 갱신식([식 7.3] = [식 6.14])
- ![](../images/equations/e%207-4.png)
  - `T = R_t + γ max_a Q(S_{t+1}, a)`로 묶으면([식 7.4])
  - `Q(S_t,A_t) ← Q(S_t,A_t) + α{ T - Q(S_t,A_t) }`
  - **볼 곳**: 이 형태가 곧 '`Q(S_t,A_t)`를 **`T`에 가까워지게** 하라'는 뜻
  - 즉 `T`를 정답으로 삼는 **회귀 문제**로 볼 수 있음 → 손실은 `(T - Q)²`
  - 표 방식의 `α`가 신경망에서는 **학습률 `lr`** 로 바뀜
- 예제 코드: [`s05_q_learning_nn.py`](s05_q_learning_nn.py) (`lr=0.01`, `ε=0.1`, 1,000 에피소드)
```python
def update(self, state, action, reward, next_state, done):
    if done:
        next_q = np.zeros(1)          # 목표 상태에서의 Q는 항상 0
    else:
        next_qs = self.qnet(next_state)
        next_q = next_qs.max(axis=1)
        next_q.unchain()              # next_q를 역전파 대상에서 제외

    target = self.gamma * next_q + reward
    qs = self.qnet(state)
    q = qs[:, action]                 # 실제로 고른 행동의 Q만 꺼냄
    loss = F.mean_squared_error(target, q)

    self.qnet.cleargrads()
    loss.backward()
    self.optimizer.update()
```
- **가장 중요한 한 줄이 `next_q.unchain()`**
  - `target`도 같은 신경망에서 나온 값이라 그대로 두면 **정답 쪽으로도 기울기가 흐름**
  - 그러면 'Q를 목표에 맞추는' 대신 '목표를 Q 쪽으로 끌어내리는' 지름길이 생겨 학습이 무너짐
  - `unchain()`은 계산 그래프를 끊어 `target`을 **상수**로 만듦(파이토치의 `detach()`에 해당)
  - 그럼에도 목표값이 매 갱신 조금씩 움직인다는 문제는 남음 → **8장 목표 신경망**
- `qs[:, action]`으로 **고른 행동의 Q만** 꺼내는 이유
  - 나머지 세 행동에 대해서는 정답을 모르므로 손실에 넣으면 안 됨
- 학습 루프에서 `state = one_hot(state)`로 감싸는 것 외에는 6장 Q 러닝과 구조가 같음
- ![](../images/figures/fig%207-14.png)
  - 에피소드별 평균 손실

  - 손실이 매끄럽게 내려가지 않는 이유 — **정답 `T` 자체가 학습 중에 계속 변함**
    (지도 학습이라면 정답이 고정이라 그림 7-9처럼 단조롭게 내려감)

    - 매개변수가 모든 칸에 공유되므로 다른 칸을 학습하면 이 칸의 출력도 함께 움직임

  - 신경망이 제 몫을 하는 것은 상태가 연속값이거나 아주 많을 때 → **8장 카트 폴·아타리**
  - 이 절의 목적은 '표를 신경망으로 바꾸는 방법'을 작은 문제에서 확인하는 것
## 7.5 정리
- `Q`를 표로 들고 있으면 상태가 많거나 **연속값**일 때 감당할 수 없음 → **신경망으로 근사**
- **DeZero 사용법**
  - `Variable`에 값을 담고, `F.*` 함수로 계산하고, `loss.backward()`로 미분
  - 기울기는 **누적**되므로 매번 `cleargrad()`/`cleargrads()`로 지울 것
  - `Model`로 계층을 묶고, `optimizer.update()`로 매개변수를 갱신
- **선형 회귀 → 신경망**
  - 선형 변환만 겹치면 결국 하나의 선형 변환 → 사이에 **활성화 함수**(시그모이드/ReLU)가 필요
  - 그 덕에 사인 곡선 같은 비선형 관계도 표현할 수 있음
- **Q 러닝을 신경망으로**
  - 상태는 **원핫 벡터**로 전처리하고 `(1, 12)`처럼 배치 차원을 붙임
  - 신경망은 `s`를 받아 **행동 수만큼** 출력 — `max_a Q(s,a)`를 한 번의 순전파로 얻기 위해
  - 갱신식 `Q ← Q + α(T - Q)`를 **목표 `T`에 대한 회귀**로 보고 `(T - Q)²`를 최소화
  - **`unchain()`으로 목표를 상수로 고정**하는 것이 핵심(파이토치의 `detach()`)
- 남은 문제들 — 8장에서 하나씩 처리
  |문제 |8장의 처방 |
  |:--|:--|
  |연속한 경험이 서로 비슷해 학습이 편향됨 |**경험 재생**(replay buffer) |
  |목표 `T`가 매 갱신 흔들림 |**목표 신경망**(target network) |
  |한 걸음씩만 갱신해 비효율적 |**미니배치** 학습 |
