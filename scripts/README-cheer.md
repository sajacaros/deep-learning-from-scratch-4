# 스터디 데일리 응원봇 세팅

매일 아침 **07:00 KST**에 Discord로 그날의 응원 문구를 보냅니다.
대상 기간: 2026-08-12 ~ 2026-10-25 (75일)

## 구성

```
.github/workflows/daily-cheer.yml   # 스케줄러 (cron)
scripts/daily_cheer.py             # 전송 스크립트 (표준 라이브러리만 사용)
scripts/messages.json              # 날짜별 문구 75개
```

## 1. Discord 웹훅 만들기

1. 문구를 받을 채널 → **채널 편집** → **연동** → **웹후크** → **새 웹후크**
2. 이름을 정하고 **웹후크 URL 복사**

> 이 URL을 아는 사람은 누구나 해당 채널에 글을 쓸 수 있습니다. 공개 저장소라면 절대 코드에 직접 넣지 마세요.

## 2. 저장소 시크릿 등록

저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

| Name | Value |
|---|---|
| `DISCORD_WEBHOOK_URL` | 1단계에서 복사한 URL |

## 3. 동작 확인

**Actions** 탭 → **스터디 데일리 응원** → **Run workflow**

- `date`: 특정 날짜 문구를 테스트하려면 입력 (예: `2026-08-16`)
- `dry_run`: 체크하면 전송 없이 로그로만 출력

로컬에서 확인하려면:

```bash
python3 scripts/daily_cheer.py --date 2026-08-16 --dry-run
```

## 알아두면 좋은 것

- **cron은 UTC 기준**입니다. `55 21 * * *` = 06:55 KST(다음 날). GitHub 스케줄은
  혼잡 시 5~20분 지연될 수 있어 정각보다 조금 앞당겨 두었습니다. 스크립트가 날짜를
  KST로 직접 판정하므로 다소 흔들려도 그날 문구가 정확히 나갑니다.
- **공개 저장소에서 60일간 커밋이 없으면 GitHub가 스케줄 워크플로를 자동 비활성화**합니다.
  스터디 기간 중 커밋이 이어지면 문제없지만, 조용해지면 Actions 탭에서 다시 켜주세요.
- 문구가 없는 날짜(기간 밖)에는 아무것도 보내지 않고 정상 종료합니다.
- 문구를 고치려면 `messages.json`만 수정하면 됩니다. 날짜 키를 추가하면 그날부터 바로 발송됩니다.

## 문구 수정 예시

```json
"2026-08-20": {
  "type": "normal",
  "msg": "여기에 원하는 내용을 쓰세요.\n줄바꿈은 \\n 입니다."
}
```

`type`은 표시 색상과 이모지를 결정합니다.

| type | 용도 | 색상 |
|---|---|---|
| `study` | 발표일 | 파랑 🎯 |
| `holiday` | 공휴일 | 노랑 🎏 |
| `normal` | 그 외 | 초록 📗 |

제목의 `D-n`은 `daily_cheer.py`의 `SCHEDULE`에서 자동 계산되므로
문구에 직접 쓸 필요가 없습니다.
